# Tori's Fahrplan

A personal learning site: Microsoft Fabric (DP-700), Azure DevOps, German A2 to B1, and AI basics (RAG, computer vision, agents).

Static site, no build step. Open `index.html` or deploy the folder as it is.

- `index.html` – page and styles
- `content.js` – all lessons and exercises
- `app.js` – exercises, simulators, routing
- `weekly.js` – "This week in AI" items
